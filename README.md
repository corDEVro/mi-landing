## 🚀 Proyectos

### ApplyFlow — Ecosistema inteligente de gestión de candidaturas

Centraliza ofertas de portales de empleo, adapta tu CV y carta de presentación con **IA**, y envía tu candidatura por email con el CV en PDF, todo desde un único panel.

- **Stack**: React + TypeScript · Java / Spring Boot · IA (OpenRouter) · PDF profesional generado al vuelo
- **Backend** desplegado con Docker en la nube · **Frontend** desplegado en Netlify
- **Enlace**: [applyflow-cordevro.netlify.app](https://applyflow-cordevro.netlify.app)

> Un proyecto real completo: autenticación, consumo de APIs externas, integración con IA, generación de documentos y despliegue automatizado en dos entornos.

## 🧰 Cómo funciona el código de este portfolio

Landing construida con **Astro + Tailwind CSS**, con:

- **Scroll suave con easing** personalizado y navegación que resalta la sección activa.
- **Animaciones de entrada escalonadas** en todo el contenido, que respetan `prefers-reduced-motion`.
- Diseño **responsive** y accesible (menú móvil, landmarks, `aria-label`).

```sh
npm install
npm run dev      # desarrollo en localhost:4321
npm run build    # build de producción en ./dist/
```
